# 界面与导航

## 顶栏

从左到右：

| 区域 | 作用 |
|---|---|
| ☰ 菜单 | 打开/关闭左侧导航 |
| 站点名 | 回到首页；配置了 logo 时显示 logo |
| 搜索框 | 输入标题，显示联想；回车搜索 |
| 显示选项 | 布局、明暗、阅读模式 |
| 账户 | 个人工具、登录/创建账号 |

手机端搜索框会折叠成放大镜图标，点开后再输入。

## 页面标题下方

标题下面是页面工具栏：

- **页面 / 讨论**：切换命名空间；
- **阅读 / 编辑 / 编辑源代码 / 查看历史**：页面操作。

手机上这些操作会变成一排图标按钮，点图标即可。

## 左侧导航

桌面端一直显示；窄屏时点左上角 ☰ 打开覆盖层。

分为「导航」「参与」「工具」三组，当前页面会高亮。

## 右侧目录

长页面会在右侧显示目录：

- 章节可嵌套；
- 阅读时当前章节自动高亮；
- 桌面端固定，滚动时一直可见；
- 手机、阅读布局和阅读模式下隐藏。

## 应用布局 vs 阅读布局

| 布局 | 看起来 |
|---|---|
| 应用布局 | 左侧导航 + 正文 + 右侧目录，像应用 |
| 阅读布局 | 隐藏导航和目录，正文居中，像阅读器 |

在顶栏「显示选项」里切换，或在 Preferences 里改。

## 阅读模式

阅读模式会进一步隐藏页面操作，只留正文，适合长文。它可以在阅读布局上叠加，也可以单独开。

## 搜索

搜索框使用 MediaWiki 自带的搜索联想；输入几个字会出现标题建议。回车后进入 `Special:Search`。

## 特殊页面

登录、历史、版本差异、Preferences 都使用 Chroma 的样式；扩展页面沿用 MediaWiki 的基础排版，不会因为换皮肤而失效。

## 常见疑问

- **编辑按钮在哪？** 在页面标题下方，不在右下角悬浮。
- **为什么没有 logo？** 没有配置 `$wgLogos` 时只显示站点名，详见 [配置](configuration.md)。
- **手机端怎么不是 MinervaNeue？** 安装 MobileFrontend 后 Chroma 会接管手机端，详见 [移动端](mobile.md)。
