# 界面与导航

## 顶栏

Chroma 的顶部应用栏包含：

- 抽屉开关；
- 站点名（配置了自定义 `$wgLogos` 时显示 logo，没有 logo 时只显示文字，不会生成首字母图标）；
- 搜索框（移动端折叠为搜索图标，使用核心搜索联想）；
- **显示选项**：布局、配色方案、阅读模式；
- **账户**：个人工具、登录/注册。

## 页面头部

页面标题在上，下面是：

- 页面标签（页面 / 讨论），带图标；
- 页面操作（阅读 / 编辑 / 编辑源代码 / 查看历史），带图标；
- 移动端操作收成 44px 图标按钮，单行排列。

## 导航抽屉

桌面端常驻，窄屏为覆盖层。分成「导航 / 参与 / 工具」三组，当前页面用胶囊高亮。

## 目录

- 嵌套章节；
- 当前章节高亮（scroll-spy）；
- 桌面端 sticky；
- 窄屏、阅读布局和阅读模式隐藏。

## 阅读布局与阅读模式

| 模式 | 行为 |
|---|---|
| 应用布局 | 抽屉 + 正文 + TOC |
| 阅读布局 | 隐藏抽屉和 TOC，正文居中 |
| 阅读模式 | 进一步隐藏页面操作、TOC，正文限宽 |

阅读布局和阅读模式可以叠加使用。

## 搜索

搜索框使用 MediaWiki 核心 `mediawiki.searchSuggest`，输入时显示标题联想；联想面板使用 Chroma 的 surface token。提交后进入 `Special:Search`。

## 移动端

参见 [移动端](mobile.md)。默认手机 UA 直接使用 Chroma 响应式布局，不需要 `?useskin=chroma`。

## 特殊页

登录（Codex 表单）、历史、版本差异、Preferences 都使用统一的 Material surface、圆角和间距；扩展页面沿用基础 prose/表格/表单样式。
